# 🏢 ESP32 LED Building Control

Система управления светодиодной адресной лентой на физическом макете здания с помощью Android-приложения через HTTP-протокол.

## 📋 Возможности
* **Покомнатное управление:** Включение/выключение любого из 8 окон на любом из 19 этажей.
* **Групповые операции:** Быстрое включение/выключение всего этажа целиком или всего здания в 1 клик.
* **Кастомизация цветов:** Возможность выбрать индивидуальный цвет (Теплый белый, Зеленый, Желтый, Красный) для каждого окна или этажа по отдельности с помощью долгого нажатия (Long Press).
* **Световое шоу:** Автоматический динамический режим анимации.
* **Синхронизация состояния:** Приложение автоматически опрашивает `/status` ESP32, восстанавливая карту цветов и включенных комнат при запуске или переподключении.
* **Современный UI:** Минималистичный монохромный дизайн с поддержкой темной/светлой темы устройства по умолчанию.

## 🛠️ Спецификация протокола связи (HTTP API)
Взаимодействие между Android-приложением и ESP32 происходит по протоколу HTTP GET на порт 80.

Команда отправляется в параметре запроса `value`:
`GET http://<ESP32_IP>/command?value=F<floor>W<room>S<state>`

* **`F` (Floor):** `1..19` (номер этажа), `0` (все этажи/все здание).
* **`W` (Window/Room):** `1..8` (номер окна), `0` (все окна этажа).
* **`S` (State):** 
  * `1` — включить свет.
  * `0` — выключить свет.
  * `2` — включить автоматический режим (Световое шоу).
  * `C0..C3` — пресеты цветов (`C0` — белый, `C1` — зеленый, `C2` — желтый, `C3` — красный).

### Примеры команд:
* `F2W5S1` — включить 5-е окно на 2-м этаже.
* `F12W0S0` — выключить весь 12-й этаж.
* `F0W0S2` — запустить световое шоу на всем здании.
* `F3W4SC1` — покрасить 4-е окно на 3-м этаже в зеленый цвет.

## 💻 Установка и сборка

### 1. Прошивка ESP32
Папка: [esp32_firmware](file:///c:/Users/Domy/AndroidStudioProjects/ApplicationLedControl/esp32_firmware)
1. Откройте файл `esp32_building_controller.ino` в Arduino IDE.
2. В менеджере плат установите пакет **ESP32** (от Espressif).
3. Установите библиотеку **Adafruit NeoPixel** через Library Manager.
4. Проверьте правильность подключения пинов:
   * `LED_PIN = 18` (сигнальный пин адресной ленты).
   * `RELAY_PIN = 23` (реле питания ленты).
5. Залейте прошивку в контроллер. ESP32 раздаст защищенную Wi-Fi точку доступа:
   * **SSID:** `LED-Control`
   * **Password:** `12345678`

### 2. Android-приложение
Папка: [app](file:///c:/Users/Domy/AndroidStudioProjects/ApplicationLedControl/app)
1. Откройте проект в Android Studio (Ladybug или новее).
2. Подключитесь к Wi-Fi сети макета (`LED-Control`).
3. Запустите сборку приложения на вашем смартфоне.
4. Откройте **Параметры и темы** (иконка шестеренки справа вверху):
   * Введите IP-адрес ESP32 (по умолчанию `192.168.4.1`).
   * Нажмите **Проверить ESP32** для синхронизации.
